# OAS Outputs Directory

This directory stores operational outputs, run logs, and review summaries produced across OAS agent sessions. Keeping all outputs within the repository ensures auditable, persistent state.

## Subdirectories

- **`outputs/signals/`**: Signal Records produced during `signal-scan` runs. Named by batch or date (e.g., `SIG-20260925-sweep.md`).
- **`outputs/reviews/`**: Periodic portfolio review summaries generated by `opportunity-ledger` (Mode B) showing freshness sweeps, stale cards, and graduation alerts.
- **`outputs/graduations/`**: Detailed dossiers for opportunities that achieved repeated paid delivery (e.g., 3+ paid instances) and were approved by the founder for productization.

## Operational Rule

Never discard failed, declined, or stale runs. Every run informs the system's learning loop (Asset principle).
